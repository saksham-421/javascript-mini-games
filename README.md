# 🎮 JavaScript Mini Games

A collection of beginner-friendly browser games built using **HTML, CSS, and JavaScript**.

These projects are part of my journey to learn and practice **frontend development and JavaScript fundamentals**.

## 🎯 Games

### ❌ Tic-Tac-Toe

A two-player Tic-Tac-Toe game where players take turns placing **X** and **O**.

**Features:**

* Two-player gameplay
* Winner detection
* Winning-line animation
* Reset / switch turn functionality
* Sound effects
* Responsive design

👉 [View Tic-Tac-Toe](Tic-Tac-Toe/index.html)

### 🧠 Simon Says

A memory game where the player needs to remember and repeat an increasing sequence of colors.

**Features:**

* Random color sequences
* Increasing difficulty
* Highest-score tracking
* Button flash animations
* Game-over indication
* Responsive design

👉 [View Simon Says](Simon-Says/index.html)

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

No frameworks or external JavaScript libraries are used.
